⚙️ One-time setup required
To share trades across devices, this app uses Supabase (free cloud database).
Follow the steps below — takes about 3 minutes.
Step 1 — Go to supabase.com → Create free account → New project
Step 2 — Go to Table Editor → New table → Name: group_trades → Enable RLS: OFF
Step 3 — Add these columns: id (uuid, primary key, default: gen_random_uuid()), trader (text), pnl (float8), pair (text), count (int4), entry (text), exit_p (text), lot (text), emotions (text), note (text), ts (timestamptz, default: now())
Step 4 — Go to Project Settings → API → copy Project URL and anon public key
